# FUTURE_UIUX_01 FUTURE_UIUX_01 – Restaurant Menu & Ordering Interface

## 📌 Task Description
This task is part of the *Future Interns UI/UX Internship*.  
The goal is to design a *digital restaurant menu & ordering interface* that allows customers to:
- Browse food items by category  
- View images of dishes  
- Place orders (for dine-in or takeaway)  

---

## 🎨 Skills Gained
- Wireframing  
- UI component design  
- Layout planning  
- User flow optimization
